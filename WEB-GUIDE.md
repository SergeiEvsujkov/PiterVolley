# VolleyPiter — инструкция для веб-версии

Веб-версия работает в браузере: ничего устанавливать из магазинов не нужно.
Адрес: **https://sergeievsujkov.github.io/PiterVolley/**

---

## 1. Как открыть

1. Откройте ссылку в браузере:
   - **iPhone / iPad** — только Safari;
   - **Android** — Chrome или любой современный браузер;
   - **компьютер** — Chrome, Safari, Firefox, Edge.
2. Подождите пару секунд — данные загрузятся автоматически.

## 2. Как установить на главный экран

Установка не обязательна, но так приложение открывается без адресной строки и работает офлайн.

**iPhone / iPad (Safari):**
1. Откройте ссылку.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран Домой»** → **«Добавить»**.

**Android (Chrome):**
1. Откройте ссылку.
2. Меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).
3. Подтвердите установку.

**Компьютер (Chrome/Edge):**
1. В адресной строке справа нажмите иконку установки.
2. Или меню **⋮ → Сохранить и поделиться → Установить**.

## 3. Что внутри

| Раздел | Что там |
|---|---|
| **Главная** | статистика сезона, ближайшие и прошедшие игры, ваши избранные, соревнования, залы |
| **Календарь** | список и сетка по месяцам, фильтры по полу, году и дивизиону |
| **Дивизионы** | таблицы, общая таблица Чемпионата, игры и команды |
| **Поиск** (лупа в шапке) | команды, игроки, дивизионы |
| **Настройки** (шестерёнка) | источник и свежесть данных, избранное, поддержка проекта |

На экране игры видно дату, время, зал, судей, комментарий, счёт и партии.
Если игру правили в таблице расписания, под карточкой появляется предупреждение
«Внимание данная игра была скорректирована».

## 4. Ближайшие и прошедшие

На главной и в календаре (режим списка) есть вкладки **«Ближайшие»** и **«Прошедшие»**.

- игра считается прошедшей, если с её начала прошёл час;
- «Прошедшие» показываются свежие сверху;
- игры без назначенной даты собраны в блоке «Дата не назначена».

## 5. Избранное

- Звёздочка есть на карточке команды и игрока.
- Отмеченные команды и игроки появляются на главной, а их игры — в отдельном блоке
  «Игры избранных».
- В дивизионах и календаре есть фильтр **«Мои»**.
- Сбросить всё: **Настройки → Избранное → Сбросить избранное**.

## 6. Как обновляются данные

Данные собирает ETL на GitHub и публикует в виде одного файла `data.json`.

- при открытии приложение само проверяет свежий файл;
- при возврате в приложение — обновляет, если данным больше 10 минут;
- кнопка **«Обновить»** на главной и в настройках проверяет файл вручную.

В карточке обновления видно:
```
Данные на 25.10 в 18:11
2 ч назад
проверено в 20:05
Данные: pitervolley.ru + volleyreferee.spb.ru
```

- **«Данные на»** — когда собраны данные;
- **«проверено в»** — когда приложение последний раз скачивало файл;
- **источник** — что удалось собрать: оба источника, только сайт или только таблица.

## 7. Офлайн

После первого открытия приложение работает без сети:

- расписание и таблицы остаются доступны;
- сверху появляется плашка **«Нет сети»**;
- когда сеть возвращается, плашка исчезает сама, а данные обновляются.

## 8. Если что-то пошло не так

**Показывается старая дата в «Данные на»**
Это нормально, если ETL ещё не собрал новые данные. Нажмите «Обновить»;
если дата не меняется — значит, на сервере действительно новых данных нет.

**Страница пустая или выглядит странно**
1. Потяните страницу вниз для перезагрузки.
2. Закройте и откройте приложение.
3. Если не помогло — очистите данные сайта:
   - Android: **⋮ → Настройки сайта → Удалить данные**;
   - iPhone: **Настройки → Safari → Дополнения → Данные сайтов → Удалить**;
   - компьютер: **F12 → Application → Clear site data**.
   После этого откройте ссылку заново — данные скачаются с сервера.

**Не устанавливается на iPhone**
Установка работает только в Safari. Из Chrome на iPhone пункта
«На экран Домой» не будет.

## 9. Чем веб-версия отличается от Android

| Возможность | Веб | Android |
|---|---|---|
| Расписание, таблицы, поиск, избранное | да | да |
| Ручная группировка игроков | да | да |
| Работа офлайн | да | да |
| Автообновление при запуске | да | да |
| Напоминания в 18:00 | нет | да |
| Установка через магазин | нет | да |

Напоминаний в вебе нет: браузер не умеет надёжно будить приложение по расписанию.
Если нужны напоминания — используйте Android-версию.
