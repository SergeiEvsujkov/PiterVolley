# PiterVolley

Android-приложение о Первенстве и Чемпионате Санкт-Петербурга по волейболу:
календарь игр, результаты по партиям, турнирные таблицы, команды и игроки.

Данные берутся из открытых источников: [pitervolley.ru](https://pitervolley.ru)
(таблицы, результаты, календарь) и Google-таблицы расписания федерации (даты, залы).

## Структура

```
app/                 Android-приложение (Kotlin, Compose)
etl/                 офлайн-ETL на Python (для отладки и подготовки данных)
etl/out/data.json    результат ETL
docs/data.json       тот же датасет для необязательного GitHub Pages
```

## Обновление данных на устройстве

Приложение **само данные не обновляет** — только вручную. Исключение — самый первый
запуск, когда данных ещё ни разу не загружали: приложение один раз подтягивает их
с сайта (не дольше 20 секунд), чтобы сразу показать актуальное расписание.

1. На главной есть панель «Последнее обновление» с датой и кнопкой **Обновить**.
2. По нажатию скачиваются 18 страниц дивизионов с pitervolley.ru (результаты, счёт
   по партиям, календарь) и CSV Google-таблицы (1 запрос) для дат и залов.
3. Данные сопоставляются, пересобираются в датасет и сохраняются в `filesDir/data.json`;
   дата и время обновления запоминаются и показываются на главной.
4. Если сети нет или сайт недоступен — остаётся прежняя копия, панель показывает ошибку.

Составы команд при обновлении не перекачиваются (это ~170 страниц): они берутся
из вшитой копии. Обновить составы можно новым APK или через необязательный GitHub Pages.

Один человек может быть заявлен за несколько команд (в данных 1214 уникальных людей
на 1276 записей — 62 играют в двух командах). Избранное хранится по человеку
(ФИО + год рождения), поэтому звёздочка ставится один раз, а игры учитываются по всем
его командам; на экране игрока перечислены все заявки.

Уведомление о завтрашних играх избранных команд проверяется при запуске приложения
на уже загруженных данных.

## Оформление

Фирменная палитра (глубокий синий + волейбольный оранжевый), карточки игр с датой,
логотипами команд и бейджем счёта, иконки Material в навигации, адаптивная иконка
приложения (мяч на синем градиенте, генерируется скриптом `make_icon.py`).

## Экраны

| Экран | Что показывает |
|---|---|
| Главная | счётчики сезона, панель обновления, «Мои команды», ближайшие игры, соревнования, залы; обновление протяжкой вниз |
| Календарь | два режима: список по датам и календарь месяца с отметками игр; фильтр по полу |
| Дивизионы | вкладки Юноши / Девушки / Мужчины / Женщины + фильтр по годам рождения (2009–2015) |
| Дивизион | таблица (считается из протоколов), игры, команды |
| Команда | логотип, дивизион, состав с фото, игры, звёздочка «в избранное» |
| Игрок | фото, ФИО, год рождения, команда |
| Матч | дата, время, зал, счёт по партиям, переход в дивизион |
| Поиск | команды, игроки, дивизионы по подстроке (от 2 символов) |
| Залы | адреса с числом игр, список игр по залу |

Отладка: `adb shell am start -n ru.example.pitervolley/.MainActivity --es route team/11`
(маршруты: `home`, `calendar`, `divisions`, `division/<id>`, `team/<id>`, `player/<id>`,
`game/<divisionId>/<gameId>`, `search`, `venues`), для поиска — `--es q "Динамо"`.

## Сборка

```bash
export JAVA_HOME="/path/to/Android Studio/jbr"
./gradlew :app:assembleDebug
```

Требования: JDK 17+, Android SDK 37, Gradle 9.8.2 (wrapper).

## Необязательный GitHub Pages

Если нужен «лёгкий» путь обновления (1 запрос вместо 19) или обновление составов,
можно публиковать готовый JSON через GitHub Actions:

1. Запушить репозиторий на GitHub.
2. Settings → Pages → ветка `main`, папка `/docs`.
3. В `app/build.gradle.kts` указать адрес:
   `buildConfigField("String", "DATA_URL", "\"https://<user>.github.io/<repo>/data.json\"")`
   и пересобрать APK. Пустая строка (по умолчанию) — обновление напрямую с сайта.

## Ограничения

- `robots.txt` pitervolley.ru закрывает URL с `?`; приложение обращается к тем же
  страницам, что и браузер, но не чаще раза в 30 минут, чтобы не создавать нагрузку.
- Вёрстка сайта может измениться — тогда потребуется обновление приложения.
- Часть игр без даты (нет и в таблице), составы заполнены не у всех команд,
  статистики игроков источники не публикуют.
