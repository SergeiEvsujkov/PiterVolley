# PiterVolley — ETL и структура данных

Пайплайн собирает данные о волейболе Санкт-Петербурга из двух источников и отдаёт
приложению один нормализованный JSON.

## Источники

| Источник | Что берём | Особенности |
|---|---|---|
| `https://pitervolley.ru/table?tid=1..18` | дивизионы, команды, календарь игр, счёт по партиям | в `robots.txt` закрыты URL с `?` — нужно разрешение федерации для регулярного обхода |
| `https://pitervolley.ru/team?team=<id>` | состав команды: ФИО, год рождения, фото | заполнен у части команд (88 из 170 на 23.10.2026) |
| Google Sheets `1qVhAPMFcWAFylnoy2529uQzTXeBs6lOvfvpWbH2x6u4`, лист «Назначения» | даты, время, залы, судьи | результатов нет; остальные листы — копии «Назначений» |

## Запуск

```bash
python etl.py            # из кэша, докачивает отсутствующее
python etl.py --refresh  # полный пересбор сырья из сети
python etl.py --offline  # только из raw/
python validate.py       # отчёт по качеству данных
```

Результат: `out/data.json` (~600 КБ), `out/validation.txt`.

## Схема data.json

```
counts       — счётчики (divisions, teams, players, games, slots, ...)
divisions[]  — { id, title, competition, gender, birthYear, teamLabel }
teams[]      — { id, name, divisionId, logo }
players[]    — { id, name, birthYear, photo, teamId, divisionId }
games[]      — { id, divisionId, round, date, time, venue,
                 homeId, awayId, home, away, score, sets[][], slotNum, dateSource }
slots[]      — слоты расписания из таблицы: { num, date, time, group, home, away,
                 venue, games, refs[], ages[], comment, gameIds[], divisionId }
```

`date` — ISO (`2026-11-08`) или `null` («дата не назначена»).
`score` — `"3:1"`, `sets` — список партий `[[25,20],[21,25],...]`.
`dateSource: "sheet"` — дата подставлена из таблицы, потому что на сайте её ещё нет.

## Сопоставление источников

Слоты таблицы матчатся к играм сайта по полу, году рождения и похожести названий
команд (`difflib`, порог 0.80, префиксы «СШ», «СШОР», «ГБОУ» отбрасываются).
Текущий результат: 437 из 454 слотов, 74 игры получили дату из таблицы.

## Нормализация

- Названия команд сравниваются без учёта регистра, «ё», кавычек и лишних пробелов.
- Адреса: убираются заглушки `...`/`???`, нормализуются пробелы и `д. 7` → `д.7`.
- Числа из таблицы приходят как `float` (`1.0`) — приводятся к `int`.
- Возраст `2015.2014` парсится как два значения.

## Ограничения

- 62 игры на сайте без даты (в таблице их тоже нет) — показываются как «дата не назначена».
- Составы заполнены у 88 команд; статистики игроков нет ни в одном источнике.
- `slots` не содержит результатов, поэтому итоговый счёт всегда берётся с сайта.
